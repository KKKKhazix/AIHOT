# 家友计划行业配置草案

这是供评审的独立草案，不会被 AIHOT 默认构建或导入。当前仓库只加载 `industry/` 根目录下的行业配置；在正式启用前，需要确认站点名称、最终分类、实际信源和标注样本，并决定采用独立部署还是增加多行业配置支持。

## 目标读者与范围

面向 9–16 岁孩子家长，关注教育与学校、儿童青少年成长、家庭生活、健康与安全、科技对孩子和家庭的影响，以及能解决家长实际问题的服务信息。内容应提供可追溯出处；热榜只作为发现线索，不作为事实证明。

## 文件

- `taxonomy.ts`：分类、内容类型和标签词表初稿。
- `topics.json`：主题目录初稿。
- `prompts/`：预筛、评分和结构化提示词初稿。
- `source-plan.md`：议案中的候选中文信源及接入边界；未配置为可运行信源。

## 尚待确认

- 是否采用这些分类名称和边界。
- 首批实际启用的信源及其许可、稳定性和采集成本。
- 每个来源的发布主体、来源级别与参与方式。
- 100–200 条编辑标注样本；在完成校准前，不设置家友计划评分门槛。
- 站点品牌、隐私与使用规则。不得直接沿用 AIHOT 品牌或模板法律文本。
